# DevDirectory — Team Project Workspace

A responsive React + Vite team workspace for a group of developer friends. The app stores demo data in browser `localStorage`, so projects, tasks, profile edits, notes, notifications, and issue reports persist after refresh on the same browser/device.

## Run locally
```bash
npm install
npm run dev
```
Production verification:
```bash
npm run build
npm run preview
```

## Features
- Friend directory pre-populated with Pintu Developer, Jaid Khan, Aman Kumar, Ankit Chauhan, Bhumnesh, Rohit Singh, Dev Rathi, Akshara Singh Rajawat, and additional sample developer friends.
- Search friends by name, company, city, or skills; individual friend profiles.
- Create, search, inspect, edit, update status, and delete projects. Projects support description, owner, status, priority, due date, and tags.
- Kanban-style task board with To do, In progress, and Completed columns; task creation, status updates, and deletion.
- Workspace notes with create/delete actions.
- Insights dashboard with project completion, status, priority, task, and issue counts.
- Editable personal profile details, skills, links, bio, and about section.
- In-app notifications generated by workspace actions, unread indicators, mark-read, and mark-all-read.
- Issue and bug reporting with type, severity, description, contact email, report history, and status.
- Portfolio preview using profile and project data.
- Resume builder with education, experience, certifications, achievements, and browser Print → Save as PDF.
- Export workspace data to a JSON backup and reset demo data.
- Responsive layout for desktop, tablet, and mobile.

## Data and backend note
This is a functional frontend demo. User-generated content is saved to browser `localStorage`; it is not synced between devices or shared live with other users. The original JSONPlaceholder API is not used for this upgraded workspace because it does not provide a real database or durable writes. For a real multi-user deployment, connect a backend/database and real authentication before using it for sensitive information.
